# VectorQuest Agent Instructions

## Coding Conventions
- Keep scripts focused and modular; avoid monolithic files.
- Keep educational math logic pure and testable where possible.
- Use typed GDScript annotations where reasonable.
- Prefer small reusable scenes and components.

## Dependency and Asset Policy
- Do not add large binary assets.
- Do not add external dependencies unless clearly justified.
- Prefer built-in Godot drawing APIs and controls.

## Workflow Expectations
- Always update `README.md` when adding major functionality.
- Always run relevant validation steps (or clearly describe limitations if not runnable).
